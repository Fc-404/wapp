# wapp 需求说明

> 状态：v0.2（D1/D2/D3 已定，见 §5）
> 目标：把 N 个自建 Web 站点装进一个"只有内容、没有浏览器"的鸿蒙应用；加站点像加标签一样即时生效，不需要重装。

## 1. 形态（已定）

- 桌面上**只有一个图标**：`wapp`。
- 点图标 → 直接全屏打开"当前站点"，无任何原生 UI 包裹。
- 站点（标签）的管理入口 = 在桌面**长按 wapp 图标**，系统弹出快捷方式菜单 → "站点管理"。
- 应用内不设任何常驻功能区、不设唤出手势，画面 100% 属于网页。

## 2. 目标设备与分发

| 项 | 值 |
|---|---|
| 设备 | HUAWEI Pura 70 |
| 系统 | HarmonyOS 7（API 26） |
| 分发 | 仅侧载，debug 自动签名，不上架 |
| 结构 | 单 bundleName、单 HAP、2 个 UIAbility（Web / Console） |

## 3. 功能需求

### R1 站点即标签
- 站点清单在"站点管理"里增删改，保存后立即生效，**无需重新构建/安装**。
- 切换站点：在管理页点某个站点 → 全屏打开该站点（复用同一 ability，携带站点参数）。
- 站点数量按 8~12 个设计，列表可滚动。

### R2 站点身份
- 站点元数据：URL、标题、图标（来自页面 favicon/apple-touch-icon）。
- 首次添加时自动抓取标题与图标，允许手动覆盖。
- 桌面图标是 wapp 自己的图标；站点图标/标题用于**闪屏**与**管理列表**。

### R3 加载体验
- 启动即显示极简闪屏：站点 icon + 标题 + URL，无人为延时。
- 首帧（`onFirstContentfulPaint`）或 `onPageEnd` 立即撤闪屏。
- 顶部细进度条跟随 `onProgressChange`，完成后消失。
- 闪屏期间不得白屏。

### R4 全屏沉浸
- 隐藏状态栏与导航栏，内容延伸到整屏（含安全区）。
- 无地址栏/工具栏/标签栏/下拉刷新控件。

### R5 返回
- 系统侧滑返回：网页可后退则后退，否则退出。
- 网页历史完整保留。

### R6 上传
网页 `<input type="file">` 必须能弹出系统文件/图片选择器并成功上传。

### R7 登录态
- Cookie 持久化（杀进程、重启后保持）。
- 不同站点按域名天然隔离；同域不同站点会共享登录态（内核行为，接受）。

### R8 站点管理（隐藏控制台）
仅通过桌面长按快捷方式进入，内容：
- 站点列表（icon + 标题 + URL），点击即打开
- 添加 / 编辑 / 删除 / 排序
- 强刷（清该站点 HTTP 缓存 + 站点存储 + 重载）
- 网络诊断（当前地址、IPv6 可达性、证书错误摘要）
- 设置当前站点、启动时打开哪个站点

### R9 断网与错误
无网络 / DNS 失败 / 超时 / 证书错误 → 自定义错误页（原因 + 重试），不暴露内核默认错误页。

### R10 横竖屏
跟随系统旋转，旋转不重载页面、不丢滚动位置。

### R11 站点"安装"（离线缓存）
站点若自行注册 Service Worker，离线缓存可用（ArkWeb 支持 SW + Cache API）。
wapp 不额外实现离线包；管理页提供"清站点数据"用于调试。

## 4. 非目标
多标签页 UI、书签、历史管理、下载管理器、广告拦截、脚本注入框架、分屏、账号体系、上架。

## 5. 已定决策

- **D1 图标**：单 wapp 桌面图标；站点图标只用于闪屏与列表。运行时添加站点，零重建。
- **D2 控制台入口**：桌面长按 → 系统快捷方式菜单（ability `metadata` 的 `ohos.ability.shortcuts` + `resources/base/profile/shortcuts_config.json`，`wants[].parameters` 可带参）。应用内不设任何设置入口。
- **D3 离线**：不实现 PWA 安装（系统无此能力）；靠站点自身 SW + HTTP 缓存，wapp 只提供清缓存/强刷。

## 6. 硬性约束（设计依据，均已在本机 SDK 核实）

- **C1 运行时无法创建桌面图标/快捷方式**：`@ohos.bundle.shortcutManager` 只能显示/隐藏由配置静态声明的快捷方式（stage 模型写在 `resources/base/profile/shortcuts_config.json` + ability `metadata`，见 tech-stack §2），运行期不能新增。快捷方式 `wants[].parameters` 可带字符串参数，一个 ConsoleAbility 即可承接所有菜单动作。
- **C2 ArkWeb 无 PWA 安装能力**：没有 `beforeinstallprompt` / manifest 安装流程；但 Service Worker、Cache API 可用（内核 Chromium M114/M132）。配额由内核管理、可能被回收，不支持查询。
- **C3 边缘手势归系统**：沉浸模式下四边滑动被系统占用，故不设页面内手势入口。
- **C4 Cookie 库按应用共享**：隔离靠域名；同域多站点共享登录态。
- **C5 站点仅 IPv6**：手机必须处于有 IPv6 的网络。

## 7. 验收清单

| # | 操作 | 通过标准 |
|---|---|---|
| 1 | `scripts/build.sh` | exit 0，产出 signed hap |
| 2 | `hdc install -r` | 桌面只出现 1 个 wapp 图标 |
| 3 | 点图标冷启动 | ≤1s 闪屏，首帧后消失，无白屏 |
| 4 | 长按图标 | 出现"站点管理"快捷方式，点击进入管理页 |
| 5 | 管理页添加站点 | 自动抓到标题/图标，点开全屏加载，无需重装 |
| 6 | 进度条 | 随加载推进，完成后消失 |
| 7 | 飞行模式 | 自定义错误页 + 重试可用 |
| 8 | 网页上传 | 弹出系统选择器，选择后上传成功 |
| 9 | 二级页面侧滑 | 回上一页；首页侧滑退出 |
| 10 | 旋转 | 不重载、滚动位置保持 |
| 11 | 管理页强刷 | 该站点缓存/存储清空并重新请求 |
| 12 | 杀进程重开 | 登录态保持、当前站点保持 |
